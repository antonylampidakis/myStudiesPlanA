# myStudiesPlanA


Το **myStudiesPlan** είναι μια web εφαρμογή για την οργάνωση και παρακολούθηση των πανεπιστημιακών σπουδών.

### Βασικές λειτουργίες

* Καταγραφή και οργάνωση μαθημάτων
* Παρακολούθηση ολοκληρωμένων μαθημάτων
* Προβολή ακαδημαϊκής προόδου
* Αποθήκευση δεδομένων online
* Σύνδεση χρηστών
